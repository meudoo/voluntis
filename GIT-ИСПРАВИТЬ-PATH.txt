Git УЖЕ УСТАНОВЛЕН на компьютере, но PowerShell его не видит.

══════════════════════════════════════════════════════════
СПОСОБ 1 — одна команда в PowerShell (быстро)
══════════════════════════════════════════════════════════

Скопируйте и вставьте целиком, Enter:

$env:Path += ";C:\Program Files\Git\cmd"
git --version

Должно показать: git version 2.xx...

Потом те же команды для GitHub:

cd C:\Users\user\Desktop\дипломм
git init
git add .
git commit -m "VOLUNTIS"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/voluntis.git
git push -u origin main

(замените ВАШ_ЛОГИН)

══════════════════════════════════════════════════════════
СПОСОБ 2 — перезагрузка компьютера
══════════════════════════════════════════════════════════

После установки Git иногда нужен перезапуск Windows.
После перезагрузки откройте новый PowerShell → git --version

══════════════════════════════════════════════════════════
СПОСОБ 3 — GitHub Desktop (без git в PowerShell)
══════════════════════════════════════════════════════════

https://desktop.github.com
File → Add local repository → папка дипломм
Publish repository

══════════════════════════════════════════════════════════
СПОСОБ 4 — двойной клик по git-push.bat
══════════════════════════════════════════════════════════

1. Откройте файл git-push.bat в блокноте
2. Замените ВАШ_ЛОГИН на логин GitHub
3. Сохраните
4. Дважды щёлкните git-push.bat
