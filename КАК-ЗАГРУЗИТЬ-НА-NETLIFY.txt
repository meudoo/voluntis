  VOLUNTIS — как загрузить на Netlify (без ошибки API)
═══════════════════════════════════════════════════════════

НЕ загружайте на Netlify:
  ✗ всю папку «дипломм»
  ✗ папку backend
  ✗ папку public (без сборки)

ЗАГРУЖАЙТЕ только папку:
  ✓ deploy-site

───────────────────────────────────────────────────────────
ШАГ 1. Соберите папку deploy-site (на компьютере)
───────────────────────────────────────────────────────────

В PowerShell:

  cd C:\Users\user\Desktop\дипломм
  $env:BACKEND_URL="https://ВАШ-URL.onrender.com"
  npm run build:netlify

(Замените URL на свой с Render → Web Service → Live → ссылка вверху)

Появится папка:  C:\Users\user\Desktop\дипломм\deploy-site

───────────────────────────────────────────────────────────
ШАГ 2. Загрузите на Netlify
───────────────────────────────────────────────────────────

Вариант А — перетаскивание:
  1. Откройте https://app.netlify.com/drop
  2. Перетащите папку deploy-site (не «дипломм»!)

Вариант Б — через Git:
  1. Проект на GitHub
  2. Netlify → Import from Git
  3. netlify.toml подставит publish = deploy-site
  4. Environment variables → BACKEND_URL = URL Render
  5. Deploy

───────────────────────────────────────────────────────────
ШАГ 3. Render (бэкенд) обязателен
───────────────────────────────────────────────────────────

Без Render вход не работает.
Проверка: https://ВАШ-URL.onrender.com/api/health
Должно быть: {"ok":true,"service":"voluntis-api"}

На сайте: Вход → блок «Связь с API» → вставить URL → Сохранить → Проверить.

Вход: admin@example.com / admin
