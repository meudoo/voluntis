# VOLUNTIS — свой домен (традиционный способ)

**Схема:** вы покупаете имя сайта (домен) → привязываете его к серверу на **Render**, где уже крутится проект.

Netlify для этого **не нужен**.

---

## Что нужно купить / настроить

| Что | Зачем | Примерная цена |
|-----|--------|----------------|
| **Домен** | Адрес в браузере (`voluntis.ru`) | от ~199–500 ₽/год (.ru) |
| **Хостинг** | Сервер с сайтом и API | **Render Free** — $0 (или платный от $7/мес) |

Домен **не заменяет** хостинг: домен — только «адрес», сайт работает на Render.

---

## Часть 1. Сайт уже на Render

Сначала должен работать бесплатный адрес Render:

1. Код на **GitHub** (вы уже делали `git init`)
2. [render.com](https://render.com) → **Web Service**
3. **Root Directory:** `backend` | **Start:** `node server.js`
4. Статус **Live**, URL вида `https://voluntis-xxxx.onrender.com`
5. Проверка: `.../api/health` → `{"ok":true,...}`

Без этого домен некуда привязать. Подробно: **RENDER-ПОШАГОВО.md**

---

## Часть 2. Купить домен

Регистраторы (Россия / СНГ):

- [reg.ru](https://www.reg.ru) — популярно для `.ru`, `.рф`
- [timeweb.com](https://timeweb.com) — домен + иногда хостинг
- [nic.ru](https://www.nic.ru)
- [namecheap.com](https://www.namecheap.com) — если нужен `.com`

### Как купить (на примере Reg.ru)

1. Зайти на сайт регистратора
2. Поиск имени, например: `voluntis.ru`, `voluntis-site.ru`
3. Добавить в корзину → оплатить (карта)
4. В личном кабинете появится **управление доменом** / **DNS**

Имя выбирайте латиницей для простоты: `voluntis.ru`, `myvoluntis.ru`.

---

## Часть 3. Привязать домен к Render

### 3.1. В Render

1. [dashboard.render.com](https://dashboard.render.com) → ваш **Web Service**
2. Вкладка **Settings**
3. Блок **Custom Domains** → **Add Custom Domain**
4. Введите домен, например:
   - `voluntis.ru` (корень)
   - `www.voluntis.ru` (с www)
5. Render покажет, **какие DNS-записи** создать у регистратора

Обычно Render просит:

| Тип | Имя / Host | Значение |
|-----|------------|----------|
| **CNAME** | `www` | `ваш-сервис.onrender.com` |
| **ALIAS** или **A** | `@` (корень) | IP или специальное значение от Render |

Точные значения **копируйте из Render** — у каждого сервиса они свои.

### 3.2. У регистратора (Reg.ru и др.)

1. Личный кабинет → ваш домен → **DNS** / **Управление зоной**
2. Добавить записи **как в Render** (CNAME для www, для корня — как указано)
3. Удалить или не дублировать старые конфликтующие A/CNAME
4. Сохранить

Обновление DNS: от **15 минут** до **24–48 часов**.

### 3.3. HTTPS (замок в браузере)

На Render для своего домена **SSL бесплатный** (Let's Encrypt).  
После проверки DNS Render сам выпустит сертификат — ничего покупать отдельно не нужно.

---

## Часть 4. Проверка

1. `https://voluntis.ru` — открывается сайт VOLUNTIS  
2. `https://voluntis.ru/api/health` — JSON `{"ok":true,...}`  
3. Вход: `admin@example.com` / `admin`

Если работает только `www`, а без www нет — в Render добавьте оба варианта и редирект (в Settings часто есть **Redirect**).

## Типичные ошибки

| Проблема | Решение |
|----------|---------|
| Домен куплен, сайт не открывается | Сначала Live на Render; DNS как в панели Render |
| «Не защищено» / нет HTTPS | Подождать 1–24 ч после DNS; в Render статус сертификата |
| Сайт открывается, вход не работает | Открывайте **тот же домен** (не старый netlify.app) |
| Только www работает | Добавить в Render оба: `@` и `www` |
