Неверная публикация на Netlify

Вы загрузили всю папку «дипломм». Так нельзя — запросы к /api получают HTML вместо JSON.

Правильно: загрузите только папку deploy-site (создайте её командой ниже).

cd дипломм
$env:BACKEND_URL="https://ВАШ-URL.onrender.com"
npm run build:netlify

Перетащите на Netlify папку deploy-site, не «дипломм».

Открыть сайт из public/ (временно)
